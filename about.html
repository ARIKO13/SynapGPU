About

Satu aplikasi, nol server.

SynapGPU dimulai dari kebiasaan yang menjengkelkan: untuk sekadar mencoba LLM, orang dipaksa mendaftar layanan cloud, menyalin API key, dan menyerahkan filenya ke server orang lain. Aplikasi ini mengambil arah sebaliknya.

Kenapa semuanya berjalan lokal

Model dan dataset sering kali bukan file kecil, dan bukan urusan kecil juga kalau harus diunggah ke tempat lain. SynapGPU tidak punya backend di cloud: file yang kamu tarik ke jendela aplikasi dibaca dari disk komputermu sendiri, training berjalan di mesin yang sama, dan hasilnya ditulis kembali ke foldermu. Kamu bisa mematikan internet dan aplikasinya tetap bekerja.

Konsekuensinya jujur saja: performa training mengikuti perangkatmu. Tapi justru itu poinnya: kamu melihat sendiri di panel monitor apa yang terjadi pada GPU, RAM, dan SSD kamu selama proses jalan.

Desktop untuk training, web untuk mencoba

Ada dua bentuk yang sengaja dibedakan. Aplikasi desktop (installer Windows) adalah versi lengkap: training, konversi format, test, benchmark, dan monitor perangkat. Demo web di situs ini hanya antarmuka untuk mencoba, chat dengan model kecil langsung dari browser via WebGPU, tanpa instal apa pun.

Apa yang sudah dikerjakan

Dikembangkan bertahap sejak versi pertama, dengan rilis kecil-kecilan alih-alih satu lompatan besar:

  • v1.3: installer Windows resmi (wizard Next → Install → Finish), pemilihan format output GGUF/safetensors, arsitektur bawaan golongan G1-G7.
  • v1.2: training pipeline dengan pilihan konfigurasi, panel device info real-time.
  • v0.x: inti aplikasi: drag & drop multi-format, chat, benchmark GPU, monitor SSD/RAM.
