Doc

Dari download sampai chat

Enam langkah, semuanya di komputermu. Estimasi total: 10 menit, tergantung kecepatan internet saat download.

1

Download installer

Buka halaman Releases terbaru dan download SynapGPU-Setup-<versi>.exe. Di halaman yang sama ada SynapGPU-windows.zip (versi portable, tanpa instalasi) dan SHA256SUMS.txt.

2

Kalau Chrome memblokir download

Peringatan "Dangerous download blocked" adalah proteksi Safe Browsing untuk file .exe yang belum punya rekam jejak — bukan tanda file berbahaya. Cara aman melanjutkan:

  1. Buka chrome://downloads → klik Keep kalau tombolnya tersedia.
  2. Kalau tidak ada: Settings → Privacy and security → Safe Browsing → pilih sementara No protection → download ulang → klik Keep → kembalikan ke Standard protection.
3

Verifikasi file (opsional, tapi disarankan)

Bandingkan hash file yang berhasil diunduh dengan angka di SHA256SUMS.txt atau di catatan release:

Get-FileHash .\SynapGPU-Setup-1.3.0.exe

Hasilnya harus persis sama dengan yang tercantum di release. Beda satu karakter = jangan dijalankan.

4

Instal

Dobel-klik installer → ikuti wizard Next → Install → Finish. Shortcut dibuat di Start Menu (dan di desktop kalau dicentang). Versi portable: cukup ekstrak ZIP-nya lalu dobel-klik SynapGPU.exe.

5

Pakai: drag & drop → Train → Test

Jendela aplikasi muncul 3–8 detik setelah dibuka — itu normal (loading runtime). Alur kerjanya:

  1. Models — tarik file model dari file manager (GGUF, safetensors, PT/PTH, BIN, ONNX).
  2. Datasets — tarik dataset (JSONL, CSV, Parquet, TXT).
  3. Train — pilih arsitektur bawaan dan tentukan golongan target (tabel di bawah), atau custom kalau mau atur sendiri. Pilih format hasil: GGUF atau safetensors. Klik Start Training.
  4. Test — setelah selesai, model hasil training langsung bisa dicoba di chat.

6

Berbagi model hasil training

Hasil tersimpan di folder yang kamu tentukan. Format .gguf bisa langsung dipakai di llama.cpp, Ollama, atau LM Studio; .safetensors cocok untuk fine-tune lanjutan di tool lain.

Kebutuhan sistem

  • Windows 10 / 11, 64-bit. WebView2 Runtime sudah tertanam di Windows 10/11 modern.
  • RAM 8 GB ke atas disarankan. GPU opsional — berguna untuk benchmark dan inference cepat.
  • Ruang disk: sesuaikan dengan ukuran model dan dataset yang mau diproses.

FAQ

  • Jendela lama muncul setelah dobel-klik — rusak? Tidak. Runtime dimuat 3–8 detik; log tersimpan di %LOCALAPPDATA%\SynapGPU\synapgpu.log.
  • Apakah file saya diunggah ke mana pun? Tidak. Semua proses berjalan lokal; aplikasi tidak mengirim model/dataset ke server mana pun.
  • Uninstall-nya di mana? Settings → Apps → SynapGPU → Uninstall, atau shortcut Uninstall SynapGPU di Start Menu.
  • Versi portable vs installer? Isinya sama; installer menambahkan shortcut dan uninstaller, portable tinggal ekstrak dan jalankan.
